# Settings

## Netmera Panel Settings

Panel Settings are where you configure app-level behavior and admin controls.

Use them for access control, messaging defaults, integrations, and shared assets.

{% hint style="info" %}
Most teams set this up once, then revisit when they add new channels, products, or users.
{% endhint %}

### Quickstart

{% stepper %}
{% step %}

#### 1) Start with General Settings

Set naming, messaging defaults, and language.
{% endstep %}

{% step %}

#### 2) Lock down access

Create roles, assign users, and set up test devices.
{% endstep %}

{% step %}

#### 3) Standardize messaging taxonomy

Create shared categories, labels, and button sets.
{% endstep %}

{% step %}

Webhooks, landing pages, and business units.
{% endstep %}
{% endstepper %}
