# 2024

## December, 2024

This release introduces Live Activities support for real-time updates on Apple surfaces.

### Live Activities

#### Netmera Live Activities

Netmera now supports Apple Live Activities for real-time, glanceable updates.

* Show live updates on the Lock Screen, iPhone StandBy, and Dynamic Island
* Start, update, and track Live Activity events with Netmera targeting
* Use Live Activities for scenarios such as sports scores, deliveries, or fitness progress

[Live Activities](https://user.netmera.com/netmera-developer-guide/live-activities/live-activities)

## June, 2024

This release updates Firebase messaging support and refreshes onboarding dashboards.

### Mobile Push

#### Migration to HTTP v1

Firebase messaging support now aligns with newer library and device requirements.

* Upgrade to Firebase Messaging Library version `20.3.0`
* Raise the minimum supported Android version to `5.0`
* Migrate to the newer Firebase versions to keep notification support current

### Onboarding

#### New Onboarding Dashboards

Onboarding dashboards are now refreshed for newer integration flows.

* Use updated onboarding screens during platform integration
* Follow a simpler setup experience
* Align onboarding with current technologies and workflows

## May, 2024

This release expands segmentation, adds Spin to Win event visibility, and introduces a new email provider integration.

### Targeting

#### Segmentation by Last Used Device

Segmentation now supports filtering by the user's last active device.

* Open **Create New Campaign → Who → Advanced → Add Condition**
* Select **By Last Device Used**
* Target users based on their most recent device activity

<figure><img src="/files/SxqjlLx4RYkK39FHO4j7" alt="" width="375"><figcaption></figcaption></figure>

### Widgets

#### Standard Spin to Win Events

Spin to Win now emits standard events for analysis and export.

* Track `Spin To Win Shown`
* Track `Spin Button Clicked`, `Coupon Code Assigned`, `Coupon Code Assigned Failed`, and `Coupon Code Copied`
* Export these events through Event Insight for deeper analysis
