# Huawei Message Receipt

Huawei has a message delivery report feature called [**Message Receipt**](https://developer.huawei.com/consumer/en/doc/development/HMSCore-Guides/msg-receipt-guide-0000001050040176)**.** After a notification sends to device, Huawei will report the message status to Netmera. By this way, Netmera can track uninstalled devices. To be able to use this feature, you must integrate Message Receipt in Huawei App Gallery.

1. Open **App Gallery Connect** (first you need to login to your [**HMS**](https://developer.huawei.com/consumer/en/service/josp/agc/index.html) account)
2. &#x20;Go to **Push Kit** section
3. Click **Settings** tab
4. Click **Enable** button for **App Receipt**

<figure><img src="/files/4X6TuSkOSUZIuwqIsfK2" alt="" width="563"><figcaption></figcaption></figure>

5. Click **New Button**
6. Enter configurations. **Callback address** and **HTTPS certificate** must be as below. After you check the details, click **Submit** button.

<figure><img src="/files/dzoM9DsgoIoFKfoeS9Kz" alt="" width="563"><figcaption></figcaption></figure>
