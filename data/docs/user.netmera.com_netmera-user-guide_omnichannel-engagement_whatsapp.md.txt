### Quickstart: send your first WhatsApp campaign

{% stepper %}
{% step %}

#### 1) Connect WhatsApp (Meta) to Netmera

You need a Meta Business Manager + WhatsApp Business account + sending number.
{% endstep %}

{% step %}

#### 2) Create and approve templates in Meta

Businesses can start conversations only using **approved templates**.

Netmera syncs templates after approval.
{% endstep %}

{% step %}

#### 3) Import WhatsApp consent / numbers

Upload users with `Whatsapp Number` and consent, then target only eligible users.
{% endstep %}

{% step %}

#### 4) Compose + personalize and test

Map template variables (`{{1}}`, `{{2}}`) to profile attributes.
{% endstep %}

{% step %}

#### 5) Configure webhooks for analytics (recommended)

Without webhooks, sending works.

With webhooks, you get delivery + read metrics in reports.
{% endstep %}
{% endstepper %}

{% column %}
WhatsApp campaigns use **pre-approved templates**.

Netmera supports **Marketing** and **Utility** templates.

Template parts:

* Header (optional): text or media
* Body (required): up to 600 characters
* Buttons (optional): up to 2 (URL, call, copy code, quick reply)
  {% endcolumn %}
  {% endcolumns %}

{% hint style="info" %}
If you care about reporting, configure Meta webhooks.

See: [WhatsApp Integration](/netmera-user-guide/omnichannel-engagement/whatsapp/whatsapp-integration.md).
{% endhint %}

### Common use cases

* Announcing a new product or service. (Marketing)
* Sending discounts, promotions, or vouchers. (Marketing)
* Running awareness campaigns to reach large audiences. (Marketing)
* Retargeting users who recently visited your app or website. (Marketing)
* Order/payment/shipping updates (Utility)
* Appointment and reminder flows (Utility)
