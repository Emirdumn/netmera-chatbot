# Web Push

Web Push is for delivering real-time, targeted messages directly in the browser. Use it to bring users back to your site, highlight promotions, share time-sensitive updates, and engage visitors without requiring an app. Campaigns can be personalized, timed, and measured for impact, with support for rich formats, interactive prompts, and mobile web push on iOS.

#### Web Text Push

Best for announcements, reminders, and short promos.

<figure><img src="/files/eR1ZgBijdkSw9gCFxREq" alt="" width="375"><figcaption></figcaption></figure>

#### Web Image Push

Best for promos and product-led messages.

<figure><img src="/files/nIV7dq0grRGGUvkEpBkA" alt="" width="315"><figcaption></figcaption></figure>

{% hint style="info" %}
Chrome supports banner images and interactive buttons.

iOS Web Push works for **home screen web apps** (iOS/iPadOS 16.4+).
{% endhint %}

#### Fancy Box (opt-in prompt)

Fancy Box is a customizable prompt for collecting Web Push permissions.

Use it to control timing, messaging, and branding around the browser permission step.

<figure><img src="/files/uI7HPbDHue7fWwQKylDC" alt="" width="563"><figcaption></figcaption></figure>

Key capabilities:

* Enable/disable the prompt (or rely on native browser prompt only)
* “Show again after” logic for users who dismiss/decline
* Full UI customization (text, size, colors, fonts)

Full setup: [Fancy Box](/netmera-user-guide/omnichannel-engagement/web-push/fancy-box.md).

#### Mobile Web Push for iOS (iOS/iPadOS 16.4+)

iOS Web Push works for **home screen web apps**.

Users must add your website to their home screen, then opt in.

<figure><img src="/files/f93ea7wHeNAh8Y4m5gFi" alt="" width="563"><figcaption></figcaption></figure>

Key points:

* Requires iOS/iPadOS 16.4+ and Safari home screen web app flow
* Opt-in happens from the home screen app (not regular Safari tabs)
* You can target these users by filtering **Safari + Mobile**

Full setup: [Mobile Web Push for iOS](/netmera-user-guide/omnichannel-engagement/web-push/mobile-web-push-for-ios.md).
