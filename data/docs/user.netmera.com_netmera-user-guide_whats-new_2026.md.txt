# 2026

## June, 2026

This release expands analytics and engagement workflows across Funnel, Journey, Insights Board, and Widget, with more control over funnel analysis, app-side journey data, custom dashboards, and widget presentation.

### Funnel

#### Analyze Funnel Performance with Flexible Conversion Logic

Use Funnel to measure how users move through key steps, where they drop off, and how different audiences convert.

You can now:

* Select the funnel order logic that best matches your user flow.
* Set conversion windows by time or sessions.
* Count results by unique users or total event occurrences.
* Exclude users based on specific events.
* Apply audience filters directly to funnel calculations.
* Turn funnel insights into action by using the actions to create targeted audiences from users who convert or drop off at specific funnel steps.
* Detect unusual changes with anomaly detection.

Create more accurate funnels and turn user behavior into clearer conversion and drop-off insights.

[Analyze Funnel Performance with Flexible Conversion Logic](/netmera-user-guide/reports-and-analytics/analytics/funnel.md)

### Journey

#### Send Custom Data to the App through Journeys

Use **Send Data Push** to send a custom JSON payload to the mobile SDK through a silent push.

You can now:

* Send structured journey data to the app without showing a visible notification.
* Use constant values, profile attributes, or journey variables in the payload.
* Trigger app-side experiences such as content recommendations, module updates, or personalized flows.
* Pass custom context from Journey Builder to the mobile application.

This helps teams connect journey behavior with app-side experiences more flexibly.

[Send Custom Data to the App through Journeys](https://user.netmera.com/netmera-user-guide/omnichannel-engagement/journey-orchestration/journey-components/action#send-data-push-action)

#### Add Key-Value Parameters to Journey Messages

You can now define custom key-value parameters for **Send In-App**, **Send Widget**, and **Send Mobile Push** steps in Journey Builder.

Custom parameters help the application decide how or where a journey message should be handled, such as opening a specific screen, passing a deeplink, displaying an in-app message in a specific context, or controlling where a widget appears.

This helps teams make journey messages more contextual and consistent with app-side behavior.

[Add Key-Value Parameters to Journey Messages](/netmera-user-guide/omnichannel-engagement/journey-orchestration/build-journey.md#custom-parameters-for-journey-messages)

### Insights Board

#### Create Custom Event-Based Dashboards

Use **Insights Board** to build custom analytics dashboards with event-based metrics.

You can now:

* Create boards for different reporting needs.
* Define insights by selecting events and aggregations.
* Display insights as **Line**, **Bar**, **Pie**, **Number**, or **Table** cards.
* Configure each card with its own date range, chart type, size, granularity, and auto-refresh settings.

This makes it easier to monitor campaigns, releases, and key product metrics from one place.

### Widget

#### Blend Widgets Seamlessly with Your Page Design

Use the new **Transparent** container option to display widget content without the default container background, border, or shadow.

You can now:

* Make the widget container visually transparent.
* Remove default container effects such as background, border, and shadow.
* Display widget content as if it is part of the host page design.
* Use transparent mode across supported widget types.
* Keep existing widgets unchanged unless transparent mode is enabled.

This helps brands create cleaner widget designs that better match their own page or app experience.
