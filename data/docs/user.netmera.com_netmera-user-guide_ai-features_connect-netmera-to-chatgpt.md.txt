# Connect Netmera to ChatGPT

Connect ChatGPT to Netmera and turn everyday marketing questions into faster answers.

Instead of jumping across dashboards and reports, you can ask ChatGPT to analyze campaign results, compare audiences, and summarize performance in plain language.

### What marketers can do with it

Once connected, ChatGPT can help you:

* review campaign performance without pulling multiple reports,
* compare channels, segments, and conversion trends faster,
* inspect user activity, events, and message history,
* and prepare summaries your team can act on quickly.

Common marketing prompts:

* “Analyze push campaign performance for the last 30 days.”
* “Compare email and SMS engagement for last week.”
* “Show revenue trends for the last 30 days.”
* “Which campaigns had the highest click-through rate this month?”
* “Summarize last week's engagement metrics for my team.”

### How ChatGPT connects to Netmera

Netmera MCP connects ChatGPT to your Netmera app through a secure MCP connection.

That lets ChatGPT retrieve permitted data, compare results, and generate readable summaries from your Netmera workspace.

### Prerequisites

{% hint style="warning" %}
Before starting the setup, make sure you have:

* **an active ChatGPT Plus, Pro, or Team subscription,**
* access to the relevant Netmera app,
* and permission to use MCP-compatible integrations.
  {% endhint %}

### Connection Management

**Disconnect the Connection**

Go to Settings → Apps → Netmera → Disconnect

**Refresh the Connection**

Go to Settings → Apps → Netmera → Refresh

**Disable Developer Mode**

Go to Settings → Apps → Advanced settings and disable the Developer mode toggle.

{% hint style="info" %}
Existing Netmera connections will continue to work, but you will no longer be able to add new custom connectors.
{% endhint %}

### ChatGPT MCP Limitations

* Developer Mode is required to add custom connectors.
* Custom MCP connectors are not reviewed by OpenAI and may introduce potential security risks.
* OAuth authentication is required. Basic authentication is not supported.
* ChatGPT MCP support currently operates as a beta/developer feature.
* Error and debugging information may be more limited compared to Claude.

### Frequently Asked Questions

**Is Developer Mode safe?**

Developer Mode allows connections to custom MCP servers that are not reviewed by OpenAI.

Only connect to trusted MCP servers, such as Netmera.

**Do I need to accept the “I understand and want to continue” warning?**

Yes. ChatGPT requires confirmation before connecting to custom MCP servers.

**What should I do if the connection is disconnected?**

Go to: Settings → Apps → Netmera → Refresh. Re-authentication may be required.

**Can I use MCP with the free ChatGPT plan?**

No. MCP/Apps support requires a ChatGPT Plus, Pro, or Team subscription.

**What happens if I disable Developer Mode?**

Existing Netmera connections will continue to work, but you will not be able to add new custom connectors.

**Why is email verification required?**

For security purposes, Netmera may require email verification during the first OAuth authentication flow.

### Security Notes

* Custom MCP connectors are not reviewed by OpenAI.
* OAuth tokens are securely stored by the platform.
* ChatGPT only accesses data allowed by your granted permissions.
* You can disconnect the integration at any time.
* Review the “Reference memories and chats” setting carefully before enabling it.

### Troubleshooting

**"Developer mode required” Error**

Enable Developer Mode from Settings → Apps → Advanced settings

**"Connection failed” Error**

Verify that the MCP Server URL is correct:

```
https://ai.netmera.com/ai/mcp
```

Also make sure your internet connection is active.

**OAuth Flow Does Not Complete**

* Disable pop-up blockers
* Check browser cookie settings
* Make sure your Netmera account is active

**The App Does Not Appear in the List**

* Refresh the page
* Reopen the Apps menu
* Sign out and sign back into ChatGPT
