# Create Mobile Push

{% hint style="info" %}

#### Quick path

**Messages** → **Campaigns** → **Create New Campaign**

1. Set the campaign name and push type in [**Setup**](/netmera-user-guide/omnichannel-engagement/mobile-push/create-mobile-push/setup.md).
2. Add content and click actions in [**What**](/netmera-user-guide/omnichannel-engagement/mobile-push/create-mobile-push/what.md).
3. Define the audience in [**Who**](/netmera-user-guide/omnichannel-engagement/mobile-push/create-mobile-push/who.md).
4. Set timing, expiry, and delivery speed in [**When**](/netmera-user-guide/omnichannel-engagement/mobile-push/create-mobile-push/when.md).
5. Review, test, and send in [**GO**](/netmera-user-guide/omnichannel-engagement/mobile-push/create-mobile-push/go.md).
   {% endhint %}

Create Mobile Push is the guided flow for building a push campaign from start to send.

Use it to:

* create one-time campaigns,
* target specific users or broad audiences,
* schedule delivery now or later,
* and test the message before launch.

### Before you start

Before creating a campaign, make sure:

* your mobile push channel is already configured,
* the audience data you need already exists,
* and you know the campaign goal before choosing the format.

{% hint style="info" %}
If you plan to personalize the push, prepare the required [**Profile Attributes**](/netmera-user-guide/customer-data/profile-attributes.md) first.
{% endhint %}
