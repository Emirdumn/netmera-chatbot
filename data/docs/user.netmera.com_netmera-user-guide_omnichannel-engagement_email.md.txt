# Email

Email is for delivering rich, content-driven messages directly to subscribers’ inboxes. Use it for newsletters, lifecycle campaigns, personalized updates, and transactional notifications to drive engagement, strengthen user relationships, and nurture long-term retention.&#x20;

Campaigns can be built, scheduled, and measured, all while respecting consent and compliance requirements.

{% step %}

#### 1) Complete onboarding first

Make sure your sending domain and provider setup are ready.
{% endstep %}

{% step %}

#### 2) Build or pick a template

Create a template once, then reuse it across campaigns.
{% endstep %}

{% step %}

#### 3) Create the campaign

Follow the standard flow to select template, audience, and schedule.
{% endstep %}

{% step %}

#### 4) Respect consent and unsubscribe

Campaign emails require opt-in.

Notification emails are for essential messages.
